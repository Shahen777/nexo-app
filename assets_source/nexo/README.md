# Nexo brand sources

- `knot.svg` — the Nexo knot mark (vector, parametric source of every icon).
- `icon.png` — 512×512 app icon (knot on brand blue).
- Brand colors: blue `#2F6BFF`, navy `#0B1F3A`, white.
- Fonts: Unbounded (display) and Manrope (text), SIL Open Font License; the `.woff2` files are web subsets — use the full TTFs from Google Fonts for the app.
